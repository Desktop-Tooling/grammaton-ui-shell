= Grammaton UI Shell

Desktop UI shell (Cairo Shell peer) on an Erlang-style actor runtime in D — not a terminal or CLI shell.

== About The Project

**Grammaton UI Shell** is a non-frustrating Windows/Linux *desktop* UI shell: window management, compositing, and shell chrome in the same product category as Cairo Shell and similar structured desktops.
It is built on an Erlang-style actor runtime in native D—not a REPL, command interpreter, or POSIX login shell.

Eliminate UI stutter and hangs by treating every UI component as an isolated lightweight process (fiber) under a supervision tree.

Docs (Antora): link:docs/modules/ROOT/pages/index.adoc[overview] · link:docs/modules/ROOT/pages/architecture.adoc[architecture] · link:docs/modules/ROOT/pages/build.adoc[build] · link:docs/modules/ROOT/pages/status.adoc[status] · link:BRANDING.adoc[branding]

== Name and lore

*Short name:* **Grammaton** — the supervised desktop shell itself.

The name nods to *Equilibrium*: Grammaton Clerics who enforce calm, precise order, contrasted with the Overseer's broader gaze.
This project applies that idea to the desktop—many small, disciplined actors under supervision instead of one brittle UI thread—then returns to engineering: fibers, mailboxes, and a Cairo Shell–class shell on D.

== Getting Started

Requirements: DMD or LDC2, DUB.

[source,powershell]
----
dub test :libbeam_d
dub build
----

Phase 1 focus is `libbeam_d`. Graphics and shell UI are stubs until later phases.

== Usage

=== Packages

[cols="1,3"]
|===
| Package | Role

| `libbeam_d`
| Core actor runtime: M:N fiber scheduler, lock-free MPSC mailbox, supervision (Phase 1–2)

| `libglaze_2d`
| 2D graphics abstraction (Blend2D bindings, command batching) — Phase 3 stub

| `libshell_bridge`
| OS / Erlang IPC and raw Win32/X11 bindings — Phase 4 stub

| `actor_shell`
| Shell executable composing the libraries — Phase 5 stub
|===

=== Implementation status
